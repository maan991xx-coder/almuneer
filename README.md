# برنامج المنير

موقع متابعة برنامج المنير لحفظ المنظومات العلمية (أنوار العقول، ألفية ابن مالك، مدارج الكمال): تقارير يومية، قلادات أسبوعية، أوسمة شهرية، وتقارير جاهزة لواتساب.

- الواجهة: صفحة واحدة ثابتة (HTML/CSS/JS) تُنشر على GitHub Pages.
- البيانات وتسجيل الدخول: Supabase (المشروع `almuneer`)، والصلاحيات محمية بسياسات RLS.
- قواعد الحساب في `rules.js`.
